# 桌面自動化與巨集

bot 可以操作它所在的那台電腦：移動滑鼠、打字、送組合鍵、管理視窗、讀寫剪貼簿、截圖、在畫面上找文字／
圖片／介面元素，以及把一連串動作存成**巨集**重複執行。底層全部走桌面自動化函式庫（`je-auto-control`），
bot 只負責解析參數、本機環境設定與中止／逾時。

```{warning}
這一整組指令都是**擁有者限定**的主機控制，閘門在派發之前、不經過角色系統（`user_roles` 三份清單都空是
預設值，那時角色閘等於沒有作用）。群組裡新增的子指令自動受閘。擁有者是 `bot_config.json` 的
`owner_user_id`，其他平台各自在 `platforms.<名稱>.owner_user_ids` 列——見 {doc}`config`。
```

## 指令群一覽

| 指令群 | 做什麼 | 參考 |
|---|---|---|
| `/input` | 滑鼠（點、雙擊、拖曳、捲動、按住）、打字、組合鍵、按住不放的鍵 | `commands/input.md` |
| `/screen` | 截圖（主螢幕、整個虛擬桌面、單一視窗、區域、短 GIF）、讀單點顏色、辨識畫面文字 | `commands/screen.md` |
| `/win` | 列出、聚焦、移動、貼齊、排成格狀、最大化／最小化視窗，儲存與還原視窗配置 | `commands/win.md` |
| `/clip` | 讀寫剪貼簿的文字與圖片 | `commands/clip.md` |
| `/locate` | 在畫面上找文字、圖片、介面元素或顏色，可以找到就點、或等它出現／消失 | `commands/locate.md` |
| `/macro` | 存、錄、編輯、執行巨集 | `commands/macro.md` |
| `/watch` | 監看條件（文字、視窗、像素、介面元素、剪貼簿、行程、連接埠、背景工作），成立時通知或跑巨集 | `commands/watch.md` |
| `/proc` | 行程清單、結束行程、啟動白名單裡的程式、資源使用 | `commands/proc.md` |
| `/host` | 在主機上跑一行指令、長時間的背景工作、上傳下載檔案、緊急停止 | `commands/host.md` |
| `/schedule` | 定時跑巨集或指令，落盤後撐得過重啟 | `commands/schedule.md` |

`/proc launch` 只啟動 `bot_config.json` 的 `gui_control` 列出來的程式（白名單與別名，見 {doc}`config`）；兩份都空時
整個停用。

## 幾個先講清楚的行為

- **座標是整個虛擬桌面的座標。** 副螢幕在主螢幕右邊時 x 會超過主螢幕寬度。截圖預設只截主螢幕，要整個虛擬桌面用
  `/screen all`；`/screen info` 同時回報兩者的範圍。
- **安全桌面上送不出輸入。** 系統的權限確認畫面或鎖定畫面擋在前面時，鍵盤滑鼠指令會直接回報失敗，不會假裝送出去。
- **按住的鍵不會卡住。** `/input key down` 按住的鍵會被登記，`/input key status` 看得到、`/input key clear` 一次全放開，
  逾時也會自動放開。打字與組合鍵送到一半失敗時，已按下的鍵由函式庫自己放開。
- **找東西的成本差很多。** 讀單點顏色幾乎免費、找視窗與介面元素是毫秒到一秒、辨識文字要跑一次辨識（整個桌面三秒
  起跳）、找圖片介於中間。在巨集的迴圈裡用錯一種，整個巨集會從幾秒變成幾分鐘。
- **錯誤訊息是泛用的。** 失敗時回的是一句固定的說明（哪一步、為什麼不能做），不帶主機路徑或原始例外；細節寫進 log。

## 巨集

巨集是一行一個步驟的純文字，存起來之後用 `/macro run <名稱>` 執行；`/macro stop` 在步驟之間中止（等待中的步驟也會
被打斷）。存檔、逐行編輯、插入、刪行與列出分別是 `/macro save`、`/macro edit`、`/macro insert`、`/macro rm_line`、
`/macro list`。

### 步驟

| 步驟 | 參數 | 說明 |
|---|---|---|
| `click` / `dclick` | `x y [按鍵]` | 點一下／雙擊 |
| `move` | `x y` | 移動滑鼠 |
| `drag` | `x1 y1 x2 y2 [按鍵]` | 拖曳 |
| `scroll` | `量 [x y]` | 捲動 |
| `type` / `paste` | `文字…` | 打字／經剪貼簿貼上（中日文用 `paste` 最穩） |
| `hotkey` | `組合` | 例如 `ctrl+s` |
| `keydown` / `keyup` / `release_keys` | `鍵名` | 按住、放開、全部放開 |
| `focus` | `視窗標題片段` | 把視窗帶到前景 |
| `win` | `動作 視窗標題片段` | 視窗動作 |
| `clip` | `set 文字` | 設定剪貼簿 |
| `wait` | `秒` | 停一下 |
| `wait_window` / `wait_text` / `wait_ui` | `[秒] 目標` | 等視窗／文字／介面元素出現（預設 15 秒） |
| `wait_gone_window` / `wait_gone_text` | `[秒] 目標` | 等它消失 |
| `wait_pixel` | `x y 顏色 [秒]` | 等某一點變成某個顏色 |
| `click_text` / `ui_click` | `目標` | 找到文字／介面元素就點 |

### 控制流程

- `repeat 次數` … `end`：重複一段（可以巢狀）。
- `if_text` / `if_window` / `if_ui` / `if_pixel` 與對應的 `if_no_…` … `else` … `end`：條件分支。
- `call 名稱 [參數…]`：呼叫另一個巨集；被呼叫的巨集裡用 `$1`～`$9` 拿參數，`$$` 是字面的 `$`。`/macro run` 的
  `args` 欄位也是這樣代入。
- `stop`：提早結束整個巨集（不算失敗）。

### 上限與檢查

- 一個巨集最多 200 行；一次執行最多跑 5000 步、`repeat` 最多 1000 次、`call` 最多三層；單一等待最多 120 秒。
- **執行前整個展開檢查一遍**：每一行的動詞與參數、區塊的 `end`、每一個 `call` 的巨集存不存在與呼叫深度。任何一處
  不合法就一步都不做，直接回報是哪個巨集的第幾行。
- 巨集裡**不能**跑 shell 指令。巨集是存在磁碟上、任何有權下指令的人都能重播的東西，把指令執行藏在裡面等於做出一個
  存起來的後門。要跑指令就自己下 `/host sh run`。

### 錄製

`/macro record` 選「開始」開始錄、選「結束」停下並存檔。

```{warning}
錄製會錄到期間打的**每一個字，包含密碼**。所以它限擁有者、最長 300 秒（到點自動存檔，並在開始錄製的頻道說一聲），
`/macro show` 也只把內容送給擁有者。
```

### 排程與監看

`/schedule add`（種類選「執行巨集」）可以定時跑巨集；`/watch` 的條件成立時也能跑巨集（`run` 參數）。兩者在**建立的
時候**就做同一套展開檢查，所以存下來的排程與監看不會到點才發現巨集壞了。

## 文字辨識

`/screen text`、`/locate text …` 與巨集的文字步驟都用本機的辨識引擎（Tesseract，安裝方式見 {doc}`setup`）。語言資料
放在專案的 `ocr_tessdata/`（不在版本庫裡），這樣加一個語言不必動到引擎的安裝目錄、也不必系統管理員權限；沒指定
語言時依要找的文字自動選（含中日韓字元就加上對應語言）。引擎沒裝或缺語言資料時，指令會回一句泛用的「辨識功能
無法使用」，細節寫進 log。
