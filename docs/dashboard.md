# 本機儀表板

一頁在本機瀏覽器看的狀態總覽：批次在不在跑、做到哪個角色、佇列還剩多少、Dorossi 有沒有排隊的提問、
機器的磁碟與記憶體。它是獨立的小程式，只讀 bot 與批次寫在磁碟上的檔案，所以開關它都不會影響正在跑
的東西，也不能從頁面上改任何東西。

## 啟動

```powershell
py -3 axiomatic\dashboard_server.py                      # 預設 http://127.0.0.1:8765/
py -3 axiomatic\dashboard_server.py --platform telegram  # 讀另一個平台的狀態
```

Dorossi 的佇列與事件、產圖紀錄是**每個平台各一份**（`state/<平台>/`），所以頁首有一個平台下拉選單，
列出這台機器上有狀態資料夾的每個平台，切過去就讀那個平台的那幾塊。一開始顯示的是 `--platform` 指定的平台，
沒給就看環境變數 `AXIOMATIC_PLATFORM`，都沒有就是預設平台。批次本身（佇列檔、進度、log）全機只有一份，
不跟著切換。

在對話平台上 `/sys dashboard` 會回這個網址。位址與埠在 `bot_config.json` 的 `dashboard.host` /
`dashboard.port`（見 {doc}`config`）。

## 頁面上有什麼

| 區塊 | 內容 |
|---|---|
| 批次 | 狀態（執行中／已暫停／已停止／判斷不出）、批次標籤、目前角色、已存張數／目標與進度條、log 最後更新是多久以前 |
| 佇列 | 提示詞、角色一、角色二、負面提示詞四個佇列還剩幾筆（角色二是位置對應的，空行也算一筆） |
| Dorossi | 等待中的提問、還原失敗的筆數、最近的事件 |
| 系統 | 輸出圖片張數、專案所在磁碟的剩餘空間、記憶體使用率 |
| 最近的批次事件 | 角色開始／完成、額度等待、瀏覽器重啟、錯誤等，新的在上面 |
| 原始狀態 | 收合起來的完整 JSON，排查時用 |

頁面每 15 秒自動更新（可以關掉），跟著系統的深淺色，手機寬度也看得清楚。**狀態「判斷不出」不等於停了**：
那表示存活訊號檔讀不出來，這一頁刻意不把「不知道」講成「沒有在跑」。提示詞與角色的原文不會出現在頁面上，
只顯示資料夾名與張數。

## 對外開放

預設只綁 `127.0.0.1`。要從區網其他機器看，把 `dashboard.host` 改成 `0.0.0.0` 或區網位址；頁面是唯讀的，
但它會露出批次狀態與資料夾名，所以只在自己控制的網路上這樣做。
